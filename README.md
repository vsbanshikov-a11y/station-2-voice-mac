# Станция 2: голосовое управление Mac

**Начните с [подробной инструкции по установке](docs/INSTALL.md).** Если вы автор проекта и хотите разместить его на GitHub, смотрите [инструкцию по публикации](docs/PUBLISHING.md).

[Результаты и границы проверок](docs/VALIDATION.md) · [Безопасность](SECURITY.md) · [Как это устроено](docs/ARCHITECTURE.md)

Дополнение к [Alisa ChatGPT Voice Assistant](https://github.com/rison1337/Alisa-ChatGPT-voice-assistant): во время разговора через Яндекс Станцию 2 фраза «Переходим в ворк» открывает отдельный голосовой сеанс Codex на Mac. Фраза «Возвращаемся в чат» возвращает обычный разговор через Станцию.

Проект использует вход ChatGPT в установленном Codex и экспериментальный голосовой интерфейс Codex. Отдельный ключ OpenAI API для проверенного варианта не использовался. Доступность, лимиты подписки и совместимость этого интерфейса могут измениться. Это не официальный продукт OpenAI или Яндекса.

## Что проверено и ограничения

- Сценарий проверен на одной Станции 2 и Mac с Apple Silicon; другие модели и конфигурации не подтверждены.
- Рабочий сеанс — **Codex**, а не переключение приложения ChatGPT в Work. Его история временная и не добавляется в закреплённый чат на колонке.
- Mac должен быть включён, не спать и иметь доступ к колонке и ChatGPT. Доступ к сервисам зависит от конкретной сети и аккаунта.
- Проверен вызов Google Календаря в тестовом сеансе. Работа с приложениями и их разрешения зависят от настроек Mac. Запросы, требующие отдельного подтверждения, пока отклоняются: интерфейс подтверждения ещё не реализован.
- Во время открытого голосового чата обработанный звук микрофона передаётся на Mac по SSH для распознавания команды. Постоянная запись не сохраняется. Состояние физической кнопки микрофона проверяется с отказом при неизвестном состоянии; аппаратное испытание на других устройствах не проводилось.
- При сбое канала исходный чат должен восстановиться. Откат проверен на искусственных данных и на тестовых сокетах Станции; повреждения питания и все возможные сбои не проверены.
- Мастер на Mac рассчитан на колонку с уже работающими root/SSH. Он может предложить установку исходного нативного клиента, но не получает root, не сбрасывает колонку, не устанавливает прошивку и не настраивает VPN. Получение root и отключение обновлений могут снижать безопасность устройства.
- Новый мастер проверен в режиме чтения на настроенной колонке и на искусственных данных; полная установка мастером на втором чистом устройстве пока не подтверждена.

## Подготовка

Нужны macOS на Apple Silicon, Google Chrome, Python 3, Go, `whisper-cli` из [whisper.cpp](https://github.com/ggml-org/whisper.cpp) и установленный Codex с входом через ChatGPT. Исходный клиент для Станции может установить мастер. На Mac и колонке должна работать проверенная SSH-связь по ключу.

1. Подготовьте root и SSH для вашей Станции 2; до их получения прочитайте [ограничения](docs/ROOT.md). При отсутствии root наш мастер не меняет колонку.
2. Установите зависимости и выполните `python3 install_mac.py`. Мастер объяснит последующие шаги и запросит подтверждение перед изменениями.
3. Откройте обычный чат фразой «Алиса, открой чат», затем скажите «Переходим в ворк».

Автозапуск предлагается после отдельного подтверждения; отключение описано в инструкции. Успех зависит от версии клиента, входа Codex, настроек безопасности и сети. Существующие установка и вход не заменяются автоматически.

## Проверки

Модульные проверки: `python3 -m unittest -v test_setup_mac test_install_mac test_mac_login test_mac_native_install test_configure_mac test_mode_switch test_pipeline test_speech_segments test_frame_dispatcher test_mode_router test_voice_service test_pcm_bridge test_station_transport`. Некоторым проверкам нужны модель, `whisper-cli`, Go и соседний исходный проект. Проверки с локальными сокетами могут потребовать системного разрешения.

`cd relay && GO111MODULE=off go test -race ./...` проверяет защиту отключённого микрофона, переключение и восстановление после имитированного сбоя.

В репозиторий не включаются настройки подключения, SSH-ключи, пользовательские сессии, модель, собранные двоичные файлы и аудиофайлы, созданные системным голосом. Не добавляйте их при публикации.
