# Установка со Станции 2 и Mac

Эта версия предназначена для Яндекс Станции 2 `YNDX-00051` и Mac с Apple Silicon. Мастер на Mac готовит зависимости, проверяет устройство с уже работающим root/SSH, предлагает установить нативный голосовой клиент и открывает отдельное окно Chrome для входа. Затем он предлагает запустить клиент и включить автозапуск дополнения.

**Статус:** на одной Станции 2 и Mac проверены обычный голос, рабочий режим и автозапуск; новый мастер установки проверен на искусственных данных и в режиме чтения на уже настроенной колонке. Полный прогон мастера на второй, чистой колонке ещё не выполнен. Результат для другой прошивки не гарантируется.

## 1. Что потребуется

- Станция 2 с доступом root по SSH. Если доступа пока нет, сначала прочитайте [про получение root](ROOT.md). Мастер **не сбрасывает колонку и не получает root автоматически**.
- Mac, на котором доступна та же локальная сеть, что и у колонки. Во время работы Mac должен быть включён и не спать.
- Уже работающий SSH-ключ для входа в колонку с Mac и доверенный ключ хоста. Пароли и содержимое ключей никому не отправляйте.
- Google Chrome, Python 3.10+, Git, Go, `whisper-cli` и установленный Codex со входом через ChatGPT. Доступ к ChatGPT с Mac и колонки должен работать; если нужен VPN, настройте его отдельно.
- Свободное место на Mac для исходных файлов, сборки и модели распознавания размером около 60 МБ. Мастер проверяет место на колонке; место на Mac проверьте самостоятельно.

Рабочий голосовой сеанс использует вход ChatGPT в Codex; отдельный API-ключ на проверенной конфигурации не использовался. Голосовой интерфейс экспериментальный, и лимиты или доступность могут измениться.

## 2. Скачайте проект и проверьте программы

После публикации откройте страницу репозитория, выберите **Code → Download ZIP** и распакуйте архив. Откройте Терминал, введите `cd ` с пробелом, перетащите в окно распакованную папку и нажмите Enter.

Выполните команды по одной:

```bash
python3 --version
git --version
go version
whisper-cli --help
codex login status
```

Если Go или `whisper-cli` не установлены и у вас уже есть Homebrew, их можно установить командами `brew install go` и `brew install whisper.cpp`. Для Codex используйте [официальную инструкцию](https://developers.openai.com/codex/cli/). Войдите в Codex через ChatGPT. Проект ожидает Chrome по стандартному пути `/Applications/Google Chrome.app`.

## 3. Подтвердите SSH с Mac

Сравните ключ хоста колонки с отпечатком, полученным из доверенного источника для вашего устройства. Пример ниже показывает форму команды: замените адрес, порт и путь к ключу на свои.

```bash
ssh -T -p 2222 -i ~/.ssh/station_key root@station.local 'printf "SSH_OK\n"'
```

Не подтверждайте неизвестный или неожиданно изменившийся отпечаток. Если команда напечатала `SSH_OK`, Mac может подключиться к колонке. Мастер использует уже доверенный ключ хоста и не отключает его проверку. Если колонка настраивалась с другого компьютера, предварительно организуйте безопасный доступ с Mac; не публикуйте закрытый ключ.

## 4. Запустите мастер на Mac

Из папки проекта выполните:

```bash
python3 install_mac.py
```

Мастер спрашивает подтверждение перед изменением колонки. Он выполняет следующие этапы:

1. Проверяет программы, получает закреплённую версию [Alisa Voice](https://github.com/rison1337/Alisa-ChatGPT-voice-assistant), скачивает модель `ggml-base-q5_1.bin` и сверяет размер и SHA-256. Голосовое подтверждение создаётся локально системным голосом; аудиофайл не входит в репозиторий. Существующие несовпадающие файлы не перезаписываются. Если путь к уже существующей копии Alisa Voice нестандартный, перед запуском задайте `STATION_ALISA_REPO`.
2. Создаёт отдельную локальную конфигурацию в `~/.local/state/station2-codex-voice/`. Укажите адрес, порт и путь к SSH-ключу. Содержимое ключа и пароль вводить не нужно. Существующая конфигурация не перезаписывается.
3. Проверяет root, модель, архитектуру, прошивку, файлы пакета и место. Если Alisa Voice уже установлен, мастер его не заменяет. Для неподтверждённой прошивки он показывает предупреждение и требует отдельного подтверждения риска.
4. Для новой установки предлагает установить нативный клиент. Затем открывает **новое отдельное окно Chrome**: войдите в ChatGPT самостоятельно и вернитесь в Терминал. После вашего подтверждения программа проверяет сессию на колонке и сохраняет её только если там ещё нет входа. Существующая сессия не заменяется. Сессия на колонке даёт доступ к аккаунту, поэтому устройство и SSH-ключ нужно защищать.
5. Предлагает запустить клиент и включить автозапуск дополнения после входа в macOS. Если автозапуск не нужен, дополнение можно запускать вручную командой `python3 voice_service.py`.

Если мастер останавливается с ошибкой, прочитайте сообщение и раздел «Решение проблем» ниже. Не отключайте проверку SSH, системные защиты или проверку пакета ради продолжения.

## 5. Начните разговор

Скажите «Алиса, открой чат». Через несколько секунд скажите **«Переходим в ворк»** и дождитесь голосового подтверждения. Попросите выполнить простую задачу на Mac. Для возврата скажите **«Возвращаемся в чат»**.

Это отдельный временный голосовой сеанс **Codex**, а не переключение интерфейса ChatGPT в Work. Его история не объединяется с закреплённым чатом на колонке. Доступ к приложениям зависит от разрешений и подключённых инструментов. Запросы, требующие отдельного подтверждения, пока отклоняются: соответствующий интерфейс ещё не реализован.

## 6. Остановка и ручные команды

Если сервис запущен вручную, остановите его клавишами **Ctrl+C**. Для отключения автозапуска, созданного этим проектом:

```bash
python3 setup_mac.py remove-autostart
```

Команда запросит подтверждение и удалит только собственную запись автозапуска. Вход, модель и программы на колонке она не удаляет. Дополнительный канал пытается вернуть исходный звук при остановке или потере связи.

Для подготовки без мастера: `python3 setup_mac.py prepare`. Для проверки нативного установщика без записи: `python3 mac_native_install.py`. Дополнительные команды смотрите через `python3 mac_native_install.py --help`; установка применяется только с `--apply` и отдельным подтверждением.

## Решение проблем

- **Не найден `alisa_cli` или не та версия Alisa Voice.** Повторите `python3 setup_mac.py prepare`; если используете другую папку, задайте `STATION_ALISA_REPO`. Мастер не переключает существующий репозиторий принудительно.
- **Не хватает модели / неверная сумма.** Повторите подготовку; несовпадающий существующий файл программа не перезапишет. Проверяйте [официальный каталог модели](https://huggingface.co/ggerganov/whisper.cpp/tree/main).
- **SSH не проходит.** Проверьте адрес, порт, права ключа и ранее подтверждённый ключ хоста. Не отключайте проверку host key.
- **Нет `station-voice: listening` при ручном запуске.** Откройте обычный чат на колонке и проверьте связь Mac с ней. При временной недоступности программа повторяет подключение.
- **Фраза не распознаётся.** Проверьте кнопку микрофона и произнесите фразу целиком. При неизвестном состоянии кнопки дополнительная передача запрещается. Разные голоса и шумовые условия ещё требуют проверки.
- **Вход ChatGPT не подтверждён.** Убедитесь, что вход завершён в отдельном окне и ChatGPT доступен как с Mac, так и с колонки. Новый вход не должен заменять существующий; проверьте сеть и VPN отдельно.
- **Рабочий режим сразу закрывается.** Проверьте вход Codex, доступность ChatGPT и VPN. Подписка, ограничения и совместимость экспериментального интерфейса могут меняться.
- **Нужно подтвердить действие.** До появления интерфейса подтверждения такие запросы отклоняются. Не обходите системные защиты.

Во время открытого обычного чата звук передаётся на Mac по SSH для локального распознавания фразы. Постоянная запись не сохраняется. Не публикуйте в отчётах пароли, ключи, токены, сетевые адреса, разговоры и личные данные.
