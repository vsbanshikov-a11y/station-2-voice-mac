# Безопасность

Не размещайте в Issues, репозитории и скриншотах SSH-ключи, пароли, session cookies, OAuth-токены, содержимое `config.json`, адреса домашней сети, разговоры и записи календаря. Прежде чем делиться диагностикой, удалите личные данные.

Во время открытого чата звук с колонки передаётся на Mac для локального обнаружения команды. Рабочий голосовой сеанс использует учётную запись ChatGPT и доступные инструменты Codex. Колонка должна находиться в доверенном помещении; произнесённые рядом команды могут быть распознаны. Состояние кнопки микрофона проверяется с отказом при неизвестном состоянии, однако независимая аппаратная проверка разных устройств не выполнена.

При ошибках подключения сначала остановите дополнение. Не отключайте проверку SSH host key, защиту аккаунта или системные разрешения ради установки. Root-доступ и изменение политики обновлений — отдельные решения владельца, не выполняемые этим проектом.

Способ приватной отправки отчётов об уязвимостях автору ещё не настроен. До его появления не публикуйте секреты и воспроизводимые детали, которые могут навредить владельцам устройств, в общедоступных Issues.
